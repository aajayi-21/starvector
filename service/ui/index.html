How to run a real day

Start the server without --dev (this panel spoils the target) and with the provider key in the environment. Then the whole day runs from the page with the buttons at the top:

  1. Open today's day — shows the trial code and the commitment. (One time before the very first day: uv run python -m validation.v2 --config configs/scoring/dev-wit-mixed.json builds the commonness tables, a warm run at near zero posts.)
  2. Play: view the trial code, describe and sketch, send once.
  3. Close the day — the one live step; the server needs the key. Spend: the new drawing's embedding items.
  4. Reveal — the page shows the target, the score, the atom-by-atom report, and the secret for the commitment check.

The same steps run from the terminal: uv run python -m service.day open|close|reveal.
