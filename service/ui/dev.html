      How a day runs
      1. Open the next day — today, or the day after the latest stored one, thus test days run back to back. One active day at a time.
      2. The player sends a sketch on the main page — one send for each day.
      3. Close — scoring runs (the one live step; the server needs the provider key for a live config).
      4. Reveal — the main page shows the player their score and report; this console can see everything at each step.

      One time before the very first day: uv run python -m validation.v2 --config configs/scoring/dev-wit-mixed.json builds the commonness tables.
